# Supervised Learning Regression Project

## Overview

This project demonstrates the application of supervised machine learning regression techniques to analyze housing data and predict median house prices. The analysis was completed as part of a **Supervised Learning Regression** course, focusing on data exploration, model development, evaluation, and interpretation of results.

The project compares multiple linear regression-based models to identify the most suitable approach for accurate prediction while providing meaningful insights from the dataset.

---

## Objectives

* Explore and understand the California Housing dataset.
* Perform data preprocessing and exploratory data analysis (EDA).
* Build and compare multiple regression models.
* Evaluate model performance using standard regression metrics.
* Identify the most influential features affecting house prices.
* Present findings, limitations, and recommendations for future improvements.

---

## Dataset

This project uses the **California Housing Dataset**, which is available through the `scikit-learn` library.

**Target Variable:**

* `HouseValue` – Median house value.

**Input Features:**

* Median Income
* House Age
* Average Rooms
* Average Bedrooms
* Population
* Average Occupancy
* Latitude
* Longitude

---

## Models Implemented

* Linear Regression
* Ridge Regression
* Lasso Regression

---

## Evaluation Metrics

The models were evaluated using:

* R² Score
* Mean Absolute Error (MAE)
* Root Mean Squared Error (RMSE)

## Key Findings

* Median income is the strongest predictor of housing prices.
* Geographic location also has a significant influence on house values.
* Comparing multiple regression techniques helps identify the most effective predictive model.
* Regularized regression models can improve model stability and reduce overfitting.
